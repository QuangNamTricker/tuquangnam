🎮 Giới thiệu

Garena Auto Register Pro là công cụ tự động đăng ký tài khoản Garena với công nghệ xác thực email ảo tiên tiến, hỗ trợ proxy và lưu trữ dữ liệu trên Firebase.

🚀 Tính năng nổi bật

  • Tự động đăng ký Garena: Điền form, lấy OTP, xác nhận hoàn toàn tự động
  • Email ảo tự tạo: Sử dụng mail.tm API để tạo hộp thư tạm thời
  • Proxy Manager: Hỗ trợ proxy HTTP/HTTPS/SOCKS, tự động luân phiên
  • Firebase Cloud: Lưu trữ tài khoản lên đám mây, token vĩnh viễn
  • Kill Switch từ xa: Quản lý và vô hiệu hóa tool từ xa qua GitHub
  • Upload file user|pass: Nhập danh sách tài khoản từ file .txt
  • Tự động xóa dữ liệu: Xóa cache, cookies sau mỗi 5 tài khoản
  • Giao diện tối/ sáng: Tùy chỉnh theme theo sở thích

🔧 Yêu cầu hệ thống

  • Trình duyệt Chrome hoặc Edge (hỗ trợ extension)
  • Kết nối Internet ổn định
  • Tài khoản Firebase (để lưu trữ dữ liệu)

📌 Hướng dẫn sử dụng

  1. Đăng nhập: Sử dụng email được cấp phép để đăng nhập vào extension
  2. Cấu hình: Chọn chế độ tạo username/password (random, tùy chọn, từ file)
  3. Proxy (tùy chọn): Nhập danh sách proxy và test kết nối
  4. Mở Garena: Truy cập trang đăng ký sso.garena.com
  5. Bắt đầu: Nhấn nút "BẮT ĐẦU" để chạy tự động
